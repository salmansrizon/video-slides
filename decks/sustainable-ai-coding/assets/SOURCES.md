# Sources: টেকসই AI Coding (decks/sustainable-ai-coding)

Facts quoted on Slides 4, 13 and the talk. Check before recording; say the numbers as "প্রায়".

- Knight Capital, 1 Aug 2012: loss in ~45 minutes after a deployment left old code active on one server; press reports said ~$440M, the SEC order says over $460M. SEC press release 2013-222: https://www.sec.gov/news/press-release/2013-222
- GitLab.com, 31 Jan 2017: primary database data accidentally removed; backups failed; ~6 hours of database changes lost. GitLab postmortem, 10 Feb 2017: https://about.gitlab.com/blog/postmortem-of-database-outage-of-january-31/
- CrowdStrike, 19 Jul 2024: faulty content update; Microsoft estimated ~8.5M Windows devices affected (less than 1%). https://blogs.microsoft.com/blog/2024/07/20/helping-our-customers-through-the-crowdstrike-outage/
- Replit / SaaStr, July 2025: Replit's agent deleted a production database during a code freeze; CEO Amjad Masad called it "unacceptable and should never be possible" and announced dev/prod database separation. The Register, 22 Jul 2025: https://www.theregister.com/2025/07/22/replit_saastr_response/
- Package hallucinations: Spracklen et al., "We Have a Package for You!", USENIX Security 2025: 19.7% of packages recommended by 16 code models did not exist. https://www.usenix.org/conference/usenixsecurity25/presentation/spracklen
