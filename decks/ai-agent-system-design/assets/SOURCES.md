# Asset sources

## Logos

Official marks, used unmodified and only to name the products (nominative use). Fetched with motionmaxxing's fetch_logo.mjs; each folder's logo.json has the source URL and brand guidelines link.

- `logos/cursor/logo.svg`: Cursor mark, from SVGL (https://svgl.app)
- `logos/claude/logo.svg`: Claude mark, from SVGL (https://svgl.app/library/claude-ai-icon.svg)
- `logos/copilot/logo.svg`: GitHub Copilot mark, dark-background variant, from SVGL (https://svgl.app/library/copilot_dark.svg)

## Rafi (character animations)

Free animations by Aleksandr (https://lottiefiles.com/Aleksander1) on LottieFiles, under the Lottie Simple License (commercial use allowed, attribution optional). Used unmodified. Rafi is a fictional character.

- `lottie/rafi-working.json`: "Programmer", https://lottiefiles.com/free-animation/programmer-roUYZs9XSB (S3)
- `lottie/rafi-error.json`: "Programming error", https://lottiefiles.com/free-animation/programming-error-IiyIU2NO0A (S1, S13)
- `lottie/rafi-like.json`: "Man like", https://lottiefiles.com/free-animation/man-like-q6DDiq6tJx (S26)

The `.json.js` files beside them are the same data wrapped by `tools/embed.mjs` so the deck works from disk.
