# Lottie library

Free LottieFiles animations collected while casting Rafi for `decks/ai-agent-system-design`. All are public free animations under the
[Lottie Simple License](https://lottiefiles.com/page/license): commercial use and modification allowed, attribution optional but encouraged.
Credit the creator in the deck's `SOURCES.md` and in the video description. Open `preview.html` to see them all moving.

To use one in a Deck: copy it into `decks/<name>/assets/lottie/`, run `node tools/embed.mjs <file>`, load the generated `.json.js`,
and drive it with the `lottie` preset (see the AI system-design deck). Used so far: Aleksandr 37879, 37882, 37880 (original colors) as Rafi.
