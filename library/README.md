# Library

Assets gathered while making Decks, kept for reuse. A Deck never links here directly: copy what you need into `decks/<name>/assets/` so each Deck stays self-contained, and credit it in that Deck's `SOURCES.md`.

- `lottie/`: 28 free LottieFiles character animations (working, stressed, relaxed), grouped by creator. `INDEX.md` lists creator, license and source; `preview.html` plays them all (open it by double-click).
- `reference/learn-with-sumit-nQspigI4SY8/`: frames from the style reference video (thumbnail, contact sheets every 10 s, key frames) and `STYLE.md`, the look the Bangla explainer Decks follow.
- `logos/`: official Cursor, Claude and GitHub Copilot marks with their `logo.json` source records. Fetch more with `node .claude/skills/motionmaxxing/scripts/fetch_logo.mjs "<Brand>" <domain> --out library/logos/<brand>`.
